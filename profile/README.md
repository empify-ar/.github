# Empify

**Validá la idea, creá el ebook con IA y vendelo desde tu propia tienda.**

Empify es una plataforma argentina para crear y vender ebooks. Probás la idea con compradores simulados por IA, la IA arma el ebook, la portada y la página de venta, y lo vendés en tu tienda con Mercado Pago. A monotributistas les emite la Factura C de esas ventas en pesos. Tiene un plan gratis, sin tarjeta.

## Qué hay acá

- **[empify-ia](https://github.com/empify-ar/empify-ia)**: conectá tu IA (Claude y otros asistentes) a tu cuenta de Empify. Trae los pasos de conexión, el complemento de Claude Code y las habilidades para leer tus ventas, validar una idea y armar los textos de tus anuncios.
